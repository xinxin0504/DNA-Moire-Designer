# DNA Moiré Designer 0.9.2

DNA Moiré Designer is research software for designing DNA Moiré structures
and analysing TEM images. It provides the complete design, sequence-assignment,
and final-export workflow together with Moiré Analysis. The distribution also
contains a caDNAno companion application for inspecting and editing generated
designs while preserving sequence-bearing Designer JSON data.

## Downloads and installation

Platform installers and portable archives are published on the GitHub Releases
page for version 0.9.2. See:

- `README_WINDOWS_BUILD.md` for Windows requirements, building, and acceptance
  checks;
- `README_MACOS_APPLE_SILICON.md` for Apple Silicon compatibility and launch
  instructions.

## Source layout

- `source/designer`: DNA Moiré Designer application and design engine;
- `source/cadnano_companion`: official-base caDNAno Companion source and the
  sequence-aware JSON I/O extension;
- `build_windows`: Windows PyInstaller and Inno Setup build files;
- `build_macos`: Apple Silicon PyInstaller, signing, ZIP, and DMG build files;
- `tests`: release-surface, licensing, and companion round-trip checks;
- `licenses`: curated license texts for bundled third-party components.
